# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Othello Platform, please report it **privately**. Do **not** open a public GitHub issue.

Use GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab
2. Click **Report a vulnerability**
3. Fill in the details and submit

Alternatively, you may contact the maintainer directly.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## What to Expect

- We will acknowledge receipt as soon as possible.
- We will investigate and keep you informed of progress.
- Once a fix is ready, we will coordinate disclosure with you.

Thank you for helping keep Othello Platform and its users safe.
