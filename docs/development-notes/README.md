# Development Notes

仍在生效的工程约定、技术决策与模式记录。CLAUDE.md 是每会话自动加载的精简入口，本目录按需阅读——CLAUDE.md 末尾「更多约定与历史」小节列出各文件用途。

## 文件索引

| 文件                          | 主题                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| `01-design-and-ui.md`         | 设计稿约定、页面布局标准、主题/PWA 决策、首页导航重构        |
| `02-frontend-patterns.md`     | 全局通知、Toast 与错误态、口令房、注册协议决策               |
| `03-backend-notes.md`         | 限流可配置化等后端设计                                       |
| `04-engineering-decisions.md` | 工程决策与共享契约（BIGINT 方案取舍、AI 分析/记谱/赛季契约） |

## 新增记忆流程（来源 → 去向）

新增项目知识时按以下规则归类：

- **持续生效的约定/决策/坑** → 写入对应主题文件；若高频到每会话都需知情，同时精简补进 `CLAUDE.md`
- **已完成任务的进度/回归快照** → 写入 `.claude/local/history.md`（私有归档，gitignored，不占公开 docs；公开读者不需要作者工作日志）
- **工程决策/共享契约**（engine ↔ 前端公共知识，如 AI 分析/记谱/赛季约定）→ 写入 `04-engineering-decisions.md`（对公开读者有价值的部分提炼，完整演进在私有归档）
- **私密本地信息**（本机端口、临时账号、私有路径、仅个人环境适用的约定）→ 写入 `CLAUDE.local.md`（gitignored，不入库）
- **一次性会话临时状态** → 不保存
