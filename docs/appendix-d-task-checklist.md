# M0 · 地基（可本地对弈）

## T01 · monorepo 脚手架 + CI

- **目标**：pnpm workspace，`packages/{shared,engine}` + `apps/{web,server}` 空包可构建；`.env.example`；ESLint/Prettier/tsconfig 共享。
- **依赖**：无。
- **DoD**：`pnpm i && pnpm -r build && pnpm -r typecheck && pnpm -r test` 全绿；CI 在 PR 上跑通 `typecheck+lint+test`。

## T02 · 规则引擎（纯函数）

- **目标**：`packages/engine` 实现 `legalMoves / applyMove / isGameOver / countPieces`，bitboard 与 Board 双表示。
- **需求**：F-C-01。
- **依赖**：T01。
- **DoD**：单测覆盖 ≥ 95%，含初盘/Pass/双 pass 终局/边界反例（见附录 B F-C-01）；引擎无副作用。

## T03 · 本地对弈 UI + 离线人机（首个可玩切片）

- **目标**：`BoardCanvas` 渲染 + 合法手高亮 + 翻子动画；接 `engine` 本地与 AI（L0-L3）对弈。
- **需求**：F-C-05、（部分）F-C-01/AI。
- **依赖**：T02。
- **DoD**：无后端即可人机对弈到终局；不登录、不计分；移动端触屏可用。

## T04 · 数据层 + 共享契约

- **目标**：`migrations` 建 §4.1 全部表与索引；`packages/shared` 落地附录 C 类型 + Zod schema + DTO 映射。
- **需求**：支撑全部。
- **依赖**：T01。
- **DoD**：迁移可升/降级；`moves` 表冻结（支持后续重连/复盘）；shared 类型被 web/server 引用无循环依赖。

## T05 · 账号体系

- **目标**：注册/登录/注销/找回/重置/邮箱验证；argon2id；JWT（访问+刷新）；基础设置。
- **需求**：F-C-10/11/12/13、F-C-14。
- **依赖**：T04。
- **DoD**：按附录 B 验收；口令仅存 hash；令牌一次性/限时；接口联调通过。

# M1 · 核心对战闭环

## T06 · WS 骨架 + 首帧鉴权 + 心跳

- **目标**：ws 挂载 Fastify；首帧 `auth` 强制鉴权；信封 `{type,payload,ts}`；ping/pong；统一 error。
- **需求**：§4.3、§6.2。
- **依赖**：T05。
- **DoD**：未鉴权首帧被断（AUTH_REQUIRED）；入参过 Zod；心跳超时清理连接。

## T07 · 房间 + 大厅

- **目标**：创建/加入/自动加入/退出/列表分页；私房口令哈希。
- **需求**：F-C-07。
- **依赖**：T06。
- **DoD**：房间状态机（附录 C）正确；双方就位自动 `game_start`。

## T08 · 服务端权威对战闭环

- **目标**：每步校验 + 写 `moves` + 广播 move/pass + 服务端终局判定 `game_over` + 计时/超时判负 + 和棋/认输/取消。
- **需求**：F-C-03/04/08。
- **依赖**：T07、T02。
- **DoD**：非法手被拒且记审计；终局只由服务端产生（无客户端上报）；超时 `endReason=timeout`。

## T09 · 在线人机 Bot

- **目标**：服务端托管 Bot（复用 engine，可走 WASM 工作线程），`ai_color` 记录；思考时延预算 + 超时降深。
- **需求**：F-C-06。
- **依赖**：T08。
- **DoD**：计分人机结果与 AI 均服务端产生；不计 ELO。

## T10 · 聊天/在线列表 + 反滥用基础

- **目标**：public/room 聊天广播+持久化；在线列表；限频/屏蔽词/举报基础。
- **需求**：F-C-09、（基础）F-E-20。
- **依赖**：T06。
- **DoD**：消息广播且写 `chats`；超频被 RATE_LIMITED。

> **M1 出口**：人机（离线+在线）与人人 WS 对战可玩，服务端每步校验生效，计时/棋数/和棋/认输/取消全流程可用，聊天与在线列表上线。

# M2 · 增强能力

## T11 · ELO + 匹配（含自动匹配队列）

- **目标**：对局结束结算 ELO（K=32，仅人人）；`rating_history` 记录；按 elo 邻近区间匹配 + 排队超时放宽。
- **需求**：F-E-01、F-E-06。
- **依赖**：T08。
- **DoD**：按附录 B F-E-01/06 验收；人机对局不计 ELO。

## T12 · 提示 / 悔棋

- **目标**：hint 返合法/最优手；人机/练习悔棋回退一手（含 AI 手）。
- **需求**：F-E-02/03。
- **依赖**：T02、T08。
- **DoD**：仅人机/练习开放悔棋；服务端记录。

## T13 · 断线重连

- **目标**：`reconnect(lastSeq)` → `state_sync`（board + 增量 moves）；重连窗口内不判逃跑。
- **需求**：F-E-04。
- **依赖**：T08（需 M1 预留重连令牌/快照接口）。
- **DoD**：拔网重连后棋局一致、回合与倒计时正确恢复。

## T14 · 观战 + 观战大厅

- **目标**：`spectate_join/leave` 只读订阅；大厅列进行中对局。
- **需求**：F-E-05/10。
- **依赖**：T08。
- **DoD**：观战者收实时走子且无法影响对局。

## T15 · 复盘查看器 + 分享

- **目标**：基于 moves 回放/单步/跳转/比分变化；生成分享链接。
- **需求**：F-E-09/11。
- **依赖**：T04（moves 表）。
- **DoD**：千手对局复盘加载 < 300ms（§6.1）；分享链接可打开。

## T16 · 好友/屏蔽 + 榜单

- **目标**：好友关系、屏蔽；榜单按 elo/classic 排序分页。
- **需求**：F-E-07/08。
- **依赖**：T05、T11。
- **DoD**：屏蔽后不收其消息/挑战；榜单排名正确。

## T17 · 再战 / 好友挑战

- **目标**：`rematch` 双方确认互换执子开新局；`challenge` 向好友发起。
- **需求**：F-E-16。
- **依赖**：T16。
- **DoD**：再战/挑战可建新局。

> **M2 出口**：ELO 驱动匹配、提示/悔棋、断线重连、观战大厅、复盘分享、好友/屏蔽/榜单均可用。

# M3 · 打磨与上线

## T18 · i18n

- **目标**：vue-i18n 框架，首批 zh-CN + en，切语即时生效；文案全部走资源。
- **需求**：F-E-12。
- **依赖**：UI 基本完成（M1/M2）。
- **DoD**：无硬编码文案；缺失 key 回退默认语。

## T19 · 主题 / 无障碍 / BossKey

- **目标**：明暗主题；无障碍（aria-label、键盘栓格、高对比、色盲描边、reduced-motion）；BossKey 轻量伪装。
- **需求**：F-E-13/14。
- **依赖**：T18。
- **DoD**：键盘全流程可玩；BossKey 一键切换/恢复不依赖全屏 API。

## T20 · AI 复盘分析

- **目标**：服务端引擎批量评估每手，输出评分/评估曲线/失误标注；`EvalChart` 展示。
- **需求**：F-E-15。
- **依赖**：T09、T15。
- **DoD**：对已结束对局产出逐手评分与建议着法。

## T21 · 战术题库/每日挑战 + 标准记谱

- **目标**：引擎从历史对局生成题目 + 每日挑战；记谱导入/导出。
- **需求**：F-E-17、F-E-19。
- **依赖**：T20。
- **DoD**：作答判定对错并给解析；非法记谱报错。

## T22 · 赛季/段位/徽章

- **目标**：赛季周期重置/结算，段位按 elo 阈值晋降，成就徽章。
- **需求**：F-E-18。
- **依赖**：T11。
- **DoD**：赛季结算与段位晋降正确。

## T23 · 压测 + 安全审计 + Beta→GA

- **目标**：单节点 ≥ 5000 并发压测；安全审计（鉴权/限流/注入/隐私）；优雅重启与崩溃回放恢复验证；Beta→GA。
- **需求**：§6.1/6.2/6.5。
- **依赖**：全部功能完成。
- **DoD**：压测达目标并发与时延分位；审计无高危项；发布回滚预案就绪。

> **M3 出口**：i18n/主题/无障碍/BossKey 上线；AI 复盘/题库/记谱/赛季就绪；压测与安全审计通过，正式 GA。
