# 附录 B · 需求验收标准（Given/When/Then）

> 每条需求的可验证验收标准，按功能编号（F-C/F-E）组织。AI 开发时应据此生成单测/E2E；**未列举的行为不得自行脑补**，不确定时在主文档「待确认问题」登记。坐标约定 `x` 为列、`y` 为行，均 0-7。

---

# 一、核心需求（F-C）

## F-C-01 · 8×8 规则引擎

- **初盘**：Given 新对局，Then 棋盘为 `(3,3)=白 (3,4)=黑 (4,3)=黑 (4,4)=白`，其余为空，先手为黑。
- **合法手**：Given 初盘且轮到黑，When `legalMoves`，Then 返回恰好 4 个点：`(2,3) (3,2) (4,5) (5,4)`。
- **翻子**：Given 黑在 `(2,3)` 落子，When `applyMove`，Then 翻 `(3,3)` 为黑，黑子=4 白子=1，`nextTurn=WHITE`。
- **Pass**：Given 某方无任何合法手且对方有，Then 该方 pass、换手（记一手 `is_pass=true`）。
- **终局**：Given 双方连续 pass（均无合法手），Then `isGameOver=true`，按子数多者胜，相等为 `DRAW`。
- **反例（均应判非法）**：落子于已有子的格、无任何翻子的空格、越界坐标。
- **约束**：引擎为纯函数（同输入同输出），不持有对局状态。

## F-C-02 · 经典积分公式（展示/称号）

- **结算**：Given 人人对局结束，Then 胜 `+3` / 负 `-2` / 平 `+1`。
- **追加**：低分方胜高分方，额外 `+两人分差×20%`（取整）；平局且双方对局数差 `< 2` 时各额外 `+10%`。
- **边界**：`classicScore` 下限 `0`（不为负）；注册初始 50；L0 对局不结算。
- **逃跑判定**：仅「轮到己方且非明显优势时长时间断线」计逃跑，每 2 次 `-1`；短时掉线走重连不扣分。

## F-C-03 · 服务端每步合法性校验

- Given 客户端发 `move`，When 服务端 `legalMoves` 不含该 `pos` 或非该方回合，Then 返回 `error ILLEGAL_MOVE`，**不改棋盘、不切回合**，写 `audit_logs(action=illegal_move)`。
- **反例**：伪造 `color`、越界坐标、非自己回合落子 → 均拒绝。
- **约束**：任何计分对局的棋盘真相以服务端为准，客户端不可自行判定合法性。

## F-C-04 · 计时/棋数 + 回合时间控制

- **实时显示**：Given 对局中，When 任一手，Then 广播双方子数、当前回合、每步倒计时（重置为每步预算）。
- **超时判负**：Given 某方回合倒计时归零，When 服务端判定，Then `game_over result=对方胜 endReason=timeout`。
- **约束**：倒计时以服务端为权威，客户端仅展示；断线期间是否暂停计时见主文档待确认（默认不暂停，重连需在剩余时间内）。

## F-C-05 · 人机离线（马上玩）

- Given 选难度并开始，Then 前端加载 `engine`（WASM/TS）本地对弈，**无需登录、不计分、不计 ELO**；断网可用。

## F-C-06 · 人机在线（服务端托管 Bot）

- Given 选在线人机，Then 服务端托管 Bot 执子（`ai_color` 记录），走子经服务端写 `moves`；结果计入经典积分，**不计 ELO**。
- **约束**：计分人机的 AI 与结果均由服务端产生（防作弊）。

## F-C-07 · 人人房间

- Given 大厅，When 创建房间`(name, mode, aiLevel?)`，Then `rooms` 新行 `status=waiting`；When 另一玩家 join，Then 进入 `ready` 子阶段（双方就位、未全部准备）；When 双方均 `room_ready` 且房主 `room_start`，Then `status=playing` 并广播 `game_start`。
- 人机房（`human_vs_ai`）例外：`room_join` 即配对开局，无须准备。
- 支持：自动加入、退出房间、房间列表分页；私房需口令（哈希校验）。

## F-C-08 · 和棋/认输/取消

- **认输**：When 一方认输，Then 对方胜、`endReason=resign`、写库、不计断线。
- **和棋**：需双方 `accept` → `DRAW endReason=draw_agree`；任一方拒绝则继续对局。
- **取消本局**：未开局或双方同意 → `status=cancelled`，不计分。

## F-C-09 · 聊天/在线列表

- Given `public`/`room` 频道，When 发消息，Then 广播且持久化 `chats`；在线用户列表实时更新。

## F-C-10~13 · 账号/资料/社交查看

- **注册**：`username` 唯一，`argon2id` 存 `password_hash`，签发 JWT，`classic_score=50 elo=1500`；邮箱可选，发验证邮件，`email_verified=false`。
- **登录**：校验口令；`remember=true` → 签刷新令牌；注销使会话失效。
- **找回**：`forgot` 发重置邮件；`reset` 用令牌改口令（令牌一次性、限时）。
- **资料**：查看/修改本人资料，查看对手公开资料（ELO/战绩）。

## F-C-14 · 基础设置

- Given 设置页，When 改难度/离线开关/服务器地址/声音/刷新间隔，Then 持久化（localStorage + 账号级）并即时生效。

# 二、增强需求（F-E）

## F-E-01 · ELO 评级 + 匹配

- **评级**：Given 两名人人对手对局结束，When 结算，Then 按 ELO（`K=32`）更新双方 `elo`；定级期（前 10 局）可放大 K；**人机对局不计 ELO**。
- **匹配**：按 `elo` 邻近区间匹配对手。

## F-E-02 / 03 · 提示 / 悔棋

- **提示**：Given 人机/练习模式，When 请求 hint，Then 返回一个合法手（默认最优）。
- **悔棋**：仅人机/练习，回退一手（含 AI 的一手），服务端记录；人人对局不开放。

## F-E-04 · 断线重连

- Given 断线，When `reconnect` 带 `lastSeq`，Then 服务端回 `state_sync`（`board` + `seq > lastSeq` 的 `moves`）恢复至断线点；在重连窗口内**不判逃跑**。

## F-E-05 / 10 · 观战 + 观战大厅

- Given 旁观者 `spectate_join(gameId)`，Then 实时收 `move/pass/game_over`，**只读、不能落子、不影响对局**；观战大厅列出进行中对局。

## F-E-06 · 自动匹配队列

- Given 排队，When 匹配到相近 `elo`，Then 自动建房开局；等待超时逐步放宽区间。

## F-E-07 / 08 · 好友/屏蔽 + 榜单

- 加/删好友；屏蔽后不接收其消息/挑战；榜单按 `elo` 或 `classicScore` 排序分页。

## F-E-09 / 11 · 复盘查看器 + 分享

- Given 已结束对局，When 打开复盘，Then 可播放/单步/跳转至第 N 手/显示翻子与比分变化；生成可分享链接（权限见待确认）。

## F-E-12 / 13 / 14 · i18n / 主题 / 无障碍 / BossKey

- **i18n**：切语言即时生效（首批 zh-CN + en）。
- **主题**：明/暗切换。
- **无障碍**：格子 `aria-label`（如“D3 黑”）、全键盘可达、高对比、色盲描边/纹理区分、尊重 `prefers-reduced-motion`。
- **BossKey**：一键将标题/图标切为中性伪装并模糊页面，再按恢复（不依赖全屏 API）。

## F-E-15 · AI 复盘分析

- Given 已结束对局，When 请求分析，Then 服务端引擎批量评估每手，输出每手评分、评估曲线、妙手/失误标注、建议着法。

## F-E-16 · 再战 / 好友挑战

- **再战**：对局结束后一方发 `rematch_request`，双方 `accept` 则互换执子开新局。
- **挑战**：向指定好友发 `challenge`。

## F-E-17 · 战术题库 / 每日挑战

- 由引擎从历史对局生成“找最佳一手”题；每日挑战 + 连做激励；When 作答，Then 判定对错并给解析。

## F-E-18 · 赛季 / 段位 / 徽章

- 赛季周期重置/结算，段位按 `elo` 阈值晋降；达成发放成就徽章。

## F-E-19 · 标准记谱导入/导出

- 导出对局为标准记谱（如 `f5d6…`）；导入记谱驱动复盘/题库；非法记谱报错。

## F-E-20 · 聊天反滥用

- 消息限频、屏蔽词过滤、举报、临时禁言；对局内提供预设快捷短语/表情。
